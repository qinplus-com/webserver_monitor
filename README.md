# webserver_monitor
个人或企业站群管理，支持监控站点运行状态，支持服务器ssh（密码或秘钥）登录，支持文件上传下载，支持服务器及web站点告警，告警支持 邮件、短信、企业微信、钉钉；支持人员分组管理站点
本工具暂不开源，个人用户免费使用，
